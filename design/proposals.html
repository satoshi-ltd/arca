Boards 01

UI-DEVICES-STATUSDesktop & web · Phone · Fold

Every device row says its Arca version and whether it is online

Why. Devices only says that a device is linked: every row other than the hub and this device ends in the same grey “Linked” pill, and its subtitle repeats the platform (lowercase “android” on desktop, because platformLabel maps only darwin, linux and win32) and an address. Nobody can tell which phone still runs an old build or which device has not synced for days, although the hub already records the time of every authenticated request (devices.last_seen) and of every machine report. Only the version is missing: phones and replicas never report it.

Technical. Protocol: the machine report gains an optional version (daemon: the release constant hello() already sends; phone: Application.nativeApplicationVersion); acceptReport stores it when it is a short dotted version and ignores it when absent, so older clients just omit the segment. machines() adds version to the hub’s own entry and an online boolean per device, computed on the hub as now − devices.last_seen < 120 s (the window freshness already uses; replicas long-poll every 10 s, a background phone shows “Seen …” between runs), and keeps lastContact for the relative time. The client compares each version with the hub’s and tints only older ones; a newer device than the hub is not flagged. No new endpoint, no new table: machine_reports.report is JSON. Desktop platformLabel maps android and ios; mobile MachineRow callers build the same caption string.

Accept On desktop, web, phone and Fold every device row other than this device reads “platform · vX.Y.Z · presence”: “Online” within two minutes of the hub’s last authenticated request from it, else “Seen …” with a neutral tile; “Never connected” and “Removed” keep their tones; a version older than the hub’s is warning-tinted with a tooltip; an unreported version is omitted. No “Linked” pill or chip remains. The hub row and this device keep their pill, totals, Disconnect… and the hub address; other rows show their last address only in the tooltip. Platforms read macOS, Linux, Windows, Android, iOS. With the hub unreachable no peer reads “Online”. At 700 px and on the phone the line ellipsises from the end without hiding the version or presence. Light and dark use tokens only.

Format 02

Board

One article per idea, tagged with its task ID. It carries the ID, the area (System, Desktop, Mobile, Auto), a title, why it is worth doing, a "Now" drawing of what exists, a "Proposed" drawing, and what proves it done. A mobile board adds a Fold pair beside its phone pair.

Drawings

Both drawings use production and kit classes only, so the page reads as the app would. A drawing is never a screenshot and never introduces a colour or size outside the tokens.

Lifecycle

Idea: a board only. Approved: one ROADMAP Queue line of type ui with the board ID, whose accept is the board. Shipped: the board is deleted, the changelog and SPEC record it, and this kit is updated.

No visual part

Behaviour, data and infrastructure tasks live only in ROADMAP and never get a board.

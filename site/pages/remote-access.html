Use Arca away from home

Files you have already synced work anywhere, with no connection. To sync changes or stream from your hub, your device has to reach it, and Arca has no public relay: you choose the route.

What works with no setup

Every folder a device keeps is a complete copy. You can open and edit those files offline, and the edits sync when the hub is reachable again. The same goes for the movies, albums and tracks you downloaded beforehand.

Option 1: a private network

A private network such as Tailscale joins your devices as if they were at home. It is a separate service that you set up yourself.

  1. Install Tailscale on the hub and on every device that should reach it, phones included.
  2. Pair each device using the hub’s Tailscale address.
  3. With a Docker hub, publish the port on the server’s Tailscale address rather than on every network, and start Docker after Tailscale so that address exists. Docker can make such a device look like one on the local network; if pairing is refused, turn on Settings → Network → Allow HTTP connections on the hub.

Option 2: your own HTTPS address

If you already run a reverse proxy with a certificate, put the hub behind it. Set ARCA_WEB_ORIGIN to the exact public address, for example https://arca.example, keep the Host header intact and make sure only the proxy can reach the hub’s port. With Docker, add it under environment: in the compose file.

The hub cannot see the proxy’s encryption: to it, every device arrives over plain HTTP from the proxy. If pairing is refused, turn on Settings → Network → Allow HTTP connections on the hub.

At home

On your own network, devices can use the hub’s private address over plain HTTP once you turn on Settings → Network → Allow HTTP connections on the hub. It is off by default, and it is meant for a network you trust.

What to keep in mind

  • Arca is not end-to-end encrypted. The devices you pair are trusted with your files, and the route you choose protects the connection.
  • Pairing uses a six-digit code that works once and expires after ten minutes. A paired device keeps its access until you revoke it on the hub.
  • Never publish the hub’s port directly on the internet over plain HTTP.

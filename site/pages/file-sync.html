File sync between your own devices

Arca keeps the folders you choose on each of your devices and carries every change between them through one computer you run, your hub. There is no company server in the middle and nothing to sign up for.

Complete files, not placeholders.

Each device chooses whole folders. They download as ordinary files that open in the apps you already use, and they work without a connection.

↔

Two-way, through your hub.

Edit on your laptop or save a file from your phone and the change reaches every device that keeps that folder. Leave the hub on and each device catches up when it connects.

↶

A way back.

The hub keeps earlier versions for 30 days by default, adjustable per folder. When two devices edit the same file, Arca keeps both versions for you to review.

Which computer is the hub

A Mac, a Windows or Linux computer, or a Docker server or NAS can be the hub; phones and tablets connect to one. Restoring an earlier version needs the hub to be reachable, and adds a new version instead of rewriting history. You can set how long versions are kept per folder: Off, 1 day, 1 week, 30 days or Forever.

What sync is not

Sync is not a backup: deleting a file in a synced folder deletes it from the other copies too. History gives you a way back for as long as it is kept, and an optional full backup of the hub can run on a second computer or server. Keep an independent copy of anything important.

Arca is built for one person’s devices. It has no accounts, sharing links or per-person permissions, and it is not end-to-end encrypted: the devices you pair are trusted with your files. Away from home, a device reaches the hub through a private network or your own HTTPS address.

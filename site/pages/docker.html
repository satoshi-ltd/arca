Run your hub with Docker

An always-on hub keeps everything within reach of your devices. The Arca image runs on a home server or a NAS and is managed from your browser.

What you need

  • A computer that stays on, with Docker and Docker Compose.
  • A 64-bit Intel or AMD processor, or 64-bit ARM. The image is published for both, so it should run on a Raspberry Pi 4 or 5 with a 64-bit system, though it has not been tested on one.
  • Disk space for your files and their history.

1. Write the compose file

Save this as compose.yaml in an empty folder:

services:
  arca:
    image: satoshiltd/arca:latest
    restart: unless-stopped
    stop_grace_period: 15s
    init: true
    ports:
      - "127.0.0.1:17831:17831"
    volumes:
      - arca-state:/data/state
      - arca-files:/data/files
    security_opt:
      - no-new-privileges:true
    cap_drop:
      - ALL
    healthcheck:
      test: ["CMD", "node", "packages/cli/arca.js", "status"]
      interval: 30s
      timeout: 5s
      retries: 3
volumes:
  arca-state:
  arca-files:

The two volumes keep Arca’s state and your files apart, and both must persist. To use folders that already exist on the server, mount them instead of arca-files and make sure user 1000 owns them. Keep the state outside any folder Arca syncs.

2. Start it and open the wizard

docker compose up -d
docker compose exec arca node packages/cli/arca.js web-code

The second command prints a one-time, six-digit code that is valid for ten minutes. Open http://localhost:17831 in a browser on the server. If the server has no screen, forward the port from your computer first with ssh -L 17831:127.0.0.1:17831 your-server and open the same address there. Then follow the wizard: name the server and choose its role, enter the code and pick the folder root.

3. Let your devices reach it

The compose file above publishes the port only on the server itself. To pair other devices, choose one:

  • Your home network. Publish the port on the server’s private address instead of 127.0.0.1, then turn on Settings → Network → Allow HTTP connections on the hub. This is plain HTTP for a network you trust: anyone on it can also reach the hub’s sign-in page.
  • A private network or HTTPS. Use Tailscale or your own HTTPS address to reach the hub from anywhere. See remote access.

Then install Arca on your computer or phone, choose to pair with a hub and enter the pairing code the hub shows.

Updating

docker compose pull
docker compose up -d

The changelog marks the versions that need an updated hub.

Many files on Linux

Arca watches each folder for changes. If the server runs out of file watches, the affected folders are checked periodically instead. Raise the limit on the host, not in the container: 

echo fs.inotify.max_user_watches=524288 | sudo tee /etc/sysctl.d/60-arca-inotify.conf
sudo sysctl --system
